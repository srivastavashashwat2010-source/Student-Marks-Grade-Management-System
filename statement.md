# Problem Statement

## Project Title

Student Marks & Grade Management System

## Problem

Managing student academic records manually can be time-consuming and may result in calculation errors. It can also be difficult to search, display, and manage records efficiently.

The Student Marks & Grade Management System provides a simple Java-based solution for managing student information and academic marks.

## Objective

The main objective of this project is to develop a console-based Java application that can:

- Add student records
- Store student marks
- Display student information
- Search students using roll number
- Calculate total marks
- Calculate percentage
- Calculate grades
- Delete student records
- Validate user input
- Handle exceptions
- Demonstrate multithreading

## Scope

The system is designed as an academic project to demonstrate Java programming concepts. It currently stores data during program execution using ArrayList.

## Target Users

- Students
- Faculty members
- Academic administrators

## Major Modules

### Module 1 – Java Fundamentals

- Variables
- Data types
- Operators
- Input/output
- Conditional statements
- Loops
- Switch statements

### Module 2 – Object-Oriented Programming

- Classes and objects
- Constructors
- Encapsulation
- Inheritance
- Method overriding
- Polymorphism
- ArrayList

### Module 3 – Exception Handling and Multithreading

- Exception handling
- try-catch
- throw
- Thread
- run()
- start()
- sleep()

## Expected Outcome

The project provides a simple and reliable way to manage student academic information while demonstrating important Java programming concepts.
